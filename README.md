## S7 – AI‑Powered Dev Workspace

S7 is a modern **Next.js 16** application that gives you an AI‑assisted coding workspace with projects, an editor, and integrations.  
Use the landing page to discover the product and the projects area to create or open workspaces.

### Tech Stack

- **Framework**: Next.js (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS 4, custom UI components
- **Auth & Backend**: Clerk, Convex, Inngest
- **Editor & UI**: CodeMirror, Radix UI, XYFlow, Allotment

### Getting Started

```bash
# install dependencies
npm install

# run dev server
bun run dev
```

Then open `http://localhost:3000` in your browser.

### Main Screens

- **Landing page**: marketing hero, features, pricing, and CTA to start building.
- **Projects dashboard**: recent projects list, create new project, import from GitHub.
- **Project workspace**: split layout with project tree, editor, preview, and tools.
